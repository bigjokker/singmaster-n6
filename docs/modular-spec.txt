5. First principles (the next project)
--------------------------------------
m_i = C(N,K) with known Fibonacci (N,K). You do not need the decimal
of m_i to prove a column is empty.

Lucas: C(N,K) mod p from base-p digits of N and K.
For each prime p, compute m_i mod p with Lucas BEFORE any construction
of m_i. Modular mode must use fib_member(i, compute_m=False). It must
not call compute_m=True, comb(N,K), or bincoef on the family pair.

For prime p > k, C(x,k) is a polynomial on F_p.
If m_i mod p is not in that image, there is no integer x with C(x,k)=m_i.
That is a proof for that column.

Conservative rule (absolute):
  not in image  =>  impossible  (certificate, if you record the witness)
  in image      =>  possible    (not a hit, not a certificate)

k=2 special case (prime p>2): Legendre / Euler
  ((8m+1)/p) = -1  kills the column
  8m+1 ≡ 0 mod p   does NOT kill (do not reject)
In code, pow(a, (p-1)//2, p)==1 on an odd prime is fine.
Name it like a prime-field test. Do not say Jacobi in JSON.

Skip p <= k. Once p<=k, C(x,k) mod p is not a function of x mod p alone.
A residue image scan there would be silently wrong.

Central C(2t,t): exact_only. No modular test this round.

Already measured on this machine with real gmpy2 (Lucas only, no
engine edit). Independently rechecked after Claude claimed the same:

6. What to implement (patch the live file)
------------------------------------------
Add only. Do not rewrite nearby/collide/invert/classify.

Functions:
  primes_upto(limit)
  binom_mod_lucas(n, k, p) -> 0 .. p-1
  column_image_mod(k, p) -> set   ONLY for p>k
      For x in 0..p-1 use math.comb(x,k)%p (x<p). Not Lucas on x.
      Lucas is for the big (N,K).
  column_possible(m_mod, k, p) -> bool
      k==2: Euler/Legendre on 8*m_mod+1
      else: m_mod in image
  obstructing_prime(N, K, k, primes) -> p or None
      m_mod = lucas(N,K,p); never build m
  obstructing_prime_for_value(m, k, primes) -> p or None
      m already in RAM; m%p

Scan driver: prime is the OUTER loop. One Lucas(N,K,p) per prime,
shared across every still-open column. Drop a column from the open
set when it dies. Do not recompute Lucas once per (k,p). This is
cheap at k<=12 and is what makes k<=300 sane.

For k<=12, per-(k,p) image cache (lru_cache) is enough. Do not delay
i=9 for a full Pascal table on F_p. That table is for a later k<=300
sweep if we do one.

column_image_mod: math.comb(x,k)%p for x in 0..p-1. NOT binom_mod_lucas
on x. Lucas is only for the big family pair (N,K).

extra_reps(..., primes=None):
